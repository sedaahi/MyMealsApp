## Proje Hakkında

Cookbook, farklı yemek kategorilerini keşfetmeyi ve yemeklerin detaylarını incelemeyi sağlayan bir mobil uygulamadır. Kullanıcılar kategoriler arasında gezinebilir, yemek detaylarını görüntüleyebilir ve beğendikleri yemekleri favorilerine ekleyebilir.

## Özellikler

- Yemek kategorilerini listeleme
- Kategoriye ait yemekleri görüntüleme
- Yemek detaylarını inceleme
- Favori yemek ekleme ve favoriler ekranında görüntüleme
- Drawer ve stack navigation ile ekranlar arası geçiş

## Kullanım

Projeyi çalıştırmak için bilgisayarınızda Node.js ve Expo ortamının kurulu olması gerekir.

```bash
npm install
npm start
```

Expo geliştirme ekranı açıldıktan sonra uygulamayı Expo Go ile QR kodu tarayarak mobil cihazda çalıştırabilir veya aşağıdaki komutlardan birini kullanabilirsiniz:

```bash
npm run android
npm run ios
npm run web
```

## Kullanılan Teknolojiler
